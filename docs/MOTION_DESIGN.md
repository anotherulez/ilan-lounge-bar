# MOTION_DESIGN.md — Единая система движения (Этапы 2–6)

> Документ фиксирует архитектуру анимаций до внедрения GSAP + ScrollTrigger (выполняется после утверждения Этапа 1).

## 1. Технологическая база
- **Движок прокрутки и сцен:** `gsap` + `ScrollTrigger` + `gsap.matchMedia()`.
- **Принцип одной библиотеки:** все scroll-driven эффекты (Kinetic Typography, Immersive Fullscreen, Horizontal Visual Storytelling, аккуратные reveals) переходят на GSAP + ScrollTrigger, без дублирования скролл-слушателей из `motion`.
- **Анимируемые свойства:** только `transform` (`translate3d`, `scale`), `opacity` и `clip-path` (при необходимости маски раскрытия). Запрещена анимация `font-size`, `width`/`height` layout-пересчётами.

## 2. Единые токены движения
- **Micro-interactions:** `180 ms` (`power2.out`)
- **Component transitions:** `360 ms` (`power3.out`)
- **Image reveals:** `750 ms` (`power3.out`, дистанция `24px`)
- **Cinematic transitions:** `1100 ms` (`power2.inOut`)
- **Scroll Scrub:** `scrub: 0.8` (плавная инерция без лагов на трекпадах и колёсиках)
- **Reduced Motion:** `gsap.matchMedia()` — при `(prefers-reduced-motion: reduce)` отключаются `pin`, `scrub`, расширение и горизонтальное перемещение; все элементы рендерятся в финальном читаемом состоянии.

## 3. Архитектура трёх ключевых сцен

### 1. Kinetic Typography (`KineticSection`)
- Самостоятельный переход между информационным блоком и полноэкранной сценой.
- 3 строки («СВЕТ. / ФОРМА. / ПРОСТРАНСТВО.»), сочетание плотной заливки, контурного начертания и контролируемого выхода за край.
- Противоположное горизонтальное перемещение строк через `ScrollTrigger` + `scrub`.

### 2. Immersive Fullscreen (`ImmersiveFullscreen` — главный эффект)
- **Фаза A (Establishing Shot):** крупный архитектурный кадр в `Wide Container` (`1520px`).
- **Фаза B (Expansion):** при прокрутке контейнер плавно расширяется до границ экрана, рамки исчезают.
- **Фаза C (Immersion):** кадр занимает `100vw × 100svh` с мягким движением камеры (`scale: 1 → 1.06`).
- **Фаза D (Release):** плавное открепление без резких скачков `opacity` и переход к следующей главе.
- **Мобильные (`< 768px`):** без длительного pinning, чистый полноширинный кадр.

### 3. Horizontal Visual Storytelling (`HorizontalGallery`)
- 5 визуальных глав: `01 Пространство`, `02 Свет`, `03 Материалы`, `04 Геометрия`, `05 Гастрономия`.
- Чередование вертикальных, горизонтальных и панорамных пропорций на разной высоте.
- **Десктоп (`>= 1024px`):** `pin: true`, `scrub: 0.8`, динамический расчёт смещения по фактической `scrollWidth - clientWidth`, индикатор прогресса и смена номера главы.
- **Мобильные (`< 1024px`):** нативный CSS `scroll-snap-type: x mandatory` без принудительного вертикального скролла.
