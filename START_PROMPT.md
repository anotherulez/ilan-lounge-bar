# Стартовый промпт для запуска в Antigravity / Codex

Скопируйте текст ниже и вставьте его в первый диалог с агентом в корне проекта (где уже лежат `AGENTS.md`, `PROJECT_BRIEF.md`, `DESIGN_SPEC.md`, `IMPLEMENTATION_PLAN.md`, `ASSETS.md`, `PROGRESS.md`, `HANDOFF.md`, `QA_REPORT.md`, а также файл `Bakery.fig` и/или папка `reference/bakery-png/` с PNG-экспортами фреймов).

---

Ты работаешь над созданием демонстрационного сайта для лаундж-бара **ILAN** (Екатеринбург) на основе оригинального макета **Bakery** (TemplatesJungle) с адаптацией цветовой палитры под реальный интерьер бара.

**Твой обязательный порядок действий:**
1. Прочитай `AGENTS.md` и прими его как обязательный регламент работы (для Antigravity продублируй ключевые правила в Workspace Rules, если они ещё не настроены).
2. Изучи `PROJECT_BRIEF.md`, `DESIGN_SPEC.md`, `IMPLEMENTATION_PLAN.md`, `ASSETS.md` и проверь наличие `Bakery.fig` и/или PNG-экспортов в `reference/`. Если `.fig` технически недоступен для чтения, явно зафиксируй это и используй PNG-экспорты (или запроси их перед началом вёрстки).
3. Выполни **Этап 0 (Инициализация)** и **Этап 1 (Декомпозиция референса)**:
   - Инициализируй Git (если ещё не инициализирован) и зафиксируй базовое состояние.
   - Заполни `DESIGN_SPEC.md` точными параметрами из макета Bakery (размеры фреймов, сетка, колонки, отступы, типографика, пропорции фото, композиция секций, мобильная версия).
   - Уточни `IMPLEMENTATION_PLAN.md` и представь его на утверждение **до начала написания кода**.
4. Не переходи к написанию кода, анимациям или адаптиву одновременно. Двигайся строго по этапам из `IMPLEMENTATION_PLAN.md` (Этапы 0–9), обновляя `PROGRESS.md`, `HANDOFF.md` и делая локальный Git-коммит после каждого завершённого этапа.
5. Соблюдай иерархию источников истины и визуальные ограничения из `AGENTS.md`. Не заявляй о прохождении проверок, которые фактически не выполнялись в браузере.
